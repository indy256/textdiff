How do the comparison options work?

Ignore whitespace treats spacing and indentation differences as equal. Ignore case treats uppercase and lowercase letters as equal. Line breaks still matter. Windows and Unix line endings are treated alike.

A view for every comparison

Use side by side to read both versions together. Switch to unified for a single list, with − for removed lines and + for additions.

Can I compare files and save the result?

Open or drop a plain text file up to 2 MB in either panel. Word, PDF, and spreadsheet documents must first be exported as text. Copy or download saves all compared lines with change prefixes, including lines beyond the display limit.
